# Product editions

## Desktop Edition
Windows and Linux desktop application for device discovery, read-only diagnostics, SMART/NVMe, reports, history, file backup and future image/clone/restore workflows.

## Recovery Edition
Bootable Ubuntu Live environment for offline diagnosis, ddrescue acquisition, imaging and file recovery. UEFI is the primary target; legacy BIOS support depends on the selected base and hardware.

## Technician Edition
Professional workflow for customer/device records, service history, diagnostic evidence, reports and controlled storage operations.

All editions share domain contracts and safety policies. Their feature availability must reflect actual implementation status; planned modules must not appear as operational controls.
