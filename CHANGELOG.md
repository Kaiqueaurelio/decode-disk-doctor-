# Changelog

## 0.2.0 — 2026-11-27

- Added centralized storage safety preflight and SHA-256 operation-plan confirmation.
- Added Decode Disk Image schema v1 manifest validation and streaming chunk verification.
- Added single-file streaming backup with SHA-256 and no-overwrite publication.
- Added ddrescue first-pass planning contract and TestDisk/PhotoRec recovery preflight.
- Added initial SQLite schema for devices, jobs, audit events, backup snapshots and image chunks.
- Expanded product editions, recovery, image format, architecture and implementation audit documentation.
- No raw-device writes or recovery subprocess execution is included in this release.
